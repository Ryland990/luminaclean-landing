# LuminaClean product facts (validation file for all content)

Last synced with App Store Connect: 2026-07-18.

## Features that EXIST (live today)

- Duplicate detection: exact duplicates AND near-duplicate (similar photo)
  detection
- Similar-photo grouping — the wedge vs Apple's own Photos app: Apple only
  catches pixel-identical duplicates, not visually similar/near-duplicate
  shots
- Blur detection
- Screenshot detection
- Large-video flagging
- Free video compression for ALL users (not gated behind a paid tier)
- AI categories: Travel, People, Architecture, Pets, Food, Transport, Text,
  Nature, Screenshots, Other
- Flashback — scan by year
- Daily Bites — on-this-day resurfacing
- Swipe keep/delete UX
- In-session undo
- Deletes go to iOS's own Recently Deleted album (30-day recovery window
  before permanent removal — this is standard iOS behavior, not a
  LuminaClean feature, but it's how "deletion" always works in the app)
- Duplicate contact merging
- Live Photo → still image conversion
- Filter by file size and by media type
- 100% on-device processing via Apple's Vision framework — no cloud
  processing, no account required
- Localized in 7 languages: English + French, German, Spanish, Brazilian
  Portuguese, Simplified Chinese, Japanese, Korean (EN FR DE ES PT-BR
  ZH-Hans JA KO)

## Features that DO NOT exist (never claim)

- No Android version
- No cloud backup or cloud storage of any kind
- No weekly subscription tier
- No meme detection
- No background scanning (scanning happens in-app, user-initiated)
- No auto-delete — nothing is ever deleted without explicit user approval;
  every deletion is a user swipe/confirmation, and even then it lands in
  iOS Recently Deleted first, not gone permanently
